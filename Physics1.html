Physical Quantities

📏

A physical quantity is anything that can be measured. Every physical quantity = a number × a unit. Without a unit, a number means nothing in physics.

TypeDefinitionExamples
FundamentalCannot be derived from other quantitiesLength, Mass, Time, Temperature, Current, Luminosity, Amount
DerivedExpressed in terms of fundamental onesSpeed, Force, Energy, Pressure, Volume, Density
ScalarHas only magnitude, no directionMass, Temperature, Distance, Speed, Energy
VectorHas both magnitude and directionDisplacement, Velocity, Force, Acceleration, Momentum
🧠 Mnemonic — 7 Fundamental Quantities "Lazy Men Tend To Ignore All Clocks" Length · Mass · Time · Temperature · Intensity (Luminous) · Amount · Current (Electric)

Topic 05 / 11

Dimensional Analysis & Applications

🧮

Dimensional analysis is the most powerful problem-solving tool in physics. It lets you check equations, derive formulas, and convert units — all using just dimensions.

📐
Principle of Homogeneity: In any correct physical equation, the dimensions of every term on both sides must be identical. You cannot add metres to seconds!
#ApplicationHow It Works
1Check equation correctnessCompare dimensions on LHS vs RHS — if equal, equation may be correct
2Derive formula between quantitiesAssume power law, equate dimensions, solve for unknown exponents
3Convert units between systemsUse ratio of unit sizes: n₁u₁ = n₂u₂
Unit Conversion Formulan₁u₁ = n₂u₂ n₂ = n₁ × [M₁/M₂]ᵃ [L₁/L₂]ᵇ [T₁/T₂]ᶜ
📝 Classic Exam Problem
Q: Check if v = u + at is dimensionally correct.
LHS: [v] = [LT⁻¹]
RHS: [u] = [LT⁻¹] · [at] = [LT⁻²][T] = [LT⁻¹]
Both sides = [LT⁻¹] ✅ Dimensionally CORRECT
⚠️
Limitations: Cannot find dimensionless constants (2π, ½) · Fails if >3 unknowns · Cannot handle trig/log/exponential functions · Dimensionally correct ≠ physically correct

Topic 06 / 11

Significant Figures

🔍

Significant figures (sig figs) express the precision of a measurement — how many digits are actually reliable and meaningful.

RuleExampleSig Figs
All non-zero digits are significant45674
Zeros between non-zero digits → significant40074
Leading zeros → NOT significant0.00452
Trailing zeros after decimal → significant4.5004
Trailing zeros without decimal → ambiguous45002, 3, or 4
Scientific notation: all mantissa digits significant4.50 × 10³3
Rules for OperationsAddition / Subtraction → Result has fewest DECIMAL PLACES Multiplication / Division → Result has fewest SIGNIFICANT FIGURES
🧠 Quick Trick Start counting from the first non-zero digit going left to right. Every digit from there is significant — including zeros between digits and trailing zeros after a decimal point.
🎯 Quick Practice
Sig figs in 0.00230?
→ 3 (digits: 2, 3, 0 — leading zeros don't count; trailing zero after decimal does)
Sig figs in 1.0 × 10⁵?
→ 2 (only 1 and 0 in the mantissa count)

Topic 07 / 11

Errors in Measurement

📉

No measurement is ever perfect. The difference between the measured value and the true value is called error.

Type of ErrorCauseCan Be Eliminated?
Systematic ErrorFaulty instrument, wrong technique, personal biasYes — by correcting the source
Random ErrorUnpredictable fluctuations; changes each readingMinimised by taking many readings
Gross Error / BlunderHuman mistakes (reading wrong scale, recording error)By care and repeated reading
Key Error Formulas — Must Know!Mean value: ā = (a₁ + a₂ + ... + aₙ) / n Absolute Error: Δaᵢ = |ā − aᵢ| Mean Absolute Error: Δā = (Σ|Δaᵢ|) / n Relative Error: Δā / ā Percentage Error: (Δā / ā) × 100 %
Error Propagation — Very Important!Addition / Subtraction: ΔZ = ΔA + ΔB Multiplication / Division: ΔZ/Z = ΔA/A + ΔB/B Power rule (Z = Aⁿ): ΔZ/Z = n × (ΔA/A) General (Z = AⁿBᵐ/Cᵖ): ΔZ/Z = n(ΔA/A) + m(ΔB/B) + p(ΔC/C)
🎯
Golden Rule: In error propagation for multiplication/division, always ADD relative errors — never subtract. Errors always accumulate, they never cancel each other!

Topic 08 / 11

Accuracy vs Precision

🎯

These two terms are not the same — confusing them is one of the most common exam mistakes!

FeatureAccuracyPrecision
MeaningHow close to the TRUE valueHow close to EACH OTHER (reproducibility)
Depends onSystematic errorsRandom errors / instrument sensitivity
ExampleTrue = 10.0 kg; Measured = 10.02 kg → Accurate ✅Got 9.8, 9.8, 9.8 kg repeatedly → Precise ✅
GoalClose to true valueClose to each other
🎳
Dart Board Analogy: Darts clustered together but far from bullseye = Precise, NOT Accurate. Darts near bullseye but scattered = Accurate, NOT Precise. Darts clustered at bullseye = Both Accurate AND Precise — the goal!

Topic 09 / 11

Least Count & Vernier Callipers

🔬

Least Count (LC) is the smallest value an instrument can measure accurately. A smaller LC = higher precision.

Vernier Calliper — FormulasLC = 1 MSD − 1 VSD LC = (Value of 1 MSD) / (Total Vernier divisions) Typical LC = 0.1 mm = 0.01 cm Total Reading = MSR + (VSR × LC)
⚠️
Zero Error: When jaws are closed, if Vernier zero ≠ main scale zero.
· Positive zero error (Vernier zero RIGHT of zero) → subtract from reading
· Negative zero error (Vernier zero LEFT of zero) → add to reading
· Formula: Corrected Reading = Observed Reading − Zero Error

Topic 10 / 11

Screw Gauge (Micrometer)

🔩

The screw gauge measures very small lengths (like wire diameter, thickness of a coin) with higher precision than a Vernier calliper — up to 0.01 mm!

Screw Gauge — Key FormulasPitch = Distance moved per full rotation = Distance between consecutive threads LC = Pitch / Total circular scale divisions = 1 mm / 100 = 0.01 mm (typically) Total Reading = LSR + (CSR × LC)
InstrumentLeast CountTypical Range
Metre Scale1 mm0 – 100 cm
Vernier Calliper0.1 mm (0.01 cm)0 – ~15 cm
Screw Gauge0.01 mm (0.001 cm)0 – ~2.5 cm
💡
Backlash Error: Due to worn threads, turning the screw may not immediately move the thimble. Always approach your final reading from the same direction to avoid this error.
🤯
Mind = Blown: A screw gauge measures 0.01 mm — that's thinner than a human hair, which is ~70 µm = 0.07 mm!

Quick Revision Blast ⚡

🚀
📌 10 Must-Know Facts — Read Before Every Exam
1. SI has 7 base + 2 supplementary units
2. Force = [MLT⁻²] · Work/Energy = [ML²T⁻²] · Power = [ML²T⁻³]
3. Momentum = Impulse = [MLT⁻¹]
4. Errors in product/ratio → relative errors always ADD
5. % error in Aⁿ = n × % error in A
6. Vernier LC = 1 MSD − 1 VSD
7. Screw Gauge LC = Pitch / Circular divisions
8. Sig figs in 6.020 × 10³ = 4
9. Planck's constant h = [ML²T⁻¹]
10. Angle is dimensionless = [M⁰L⁰T⁰]
🧠 Error Formula Tree — Last Night Revision Z = A ± B → ΔZ = ΔA + ΔB Z = A × B or A/B → ΔZ/Z = ΔA/A + ΔB/B
Z = Aⁿ → ΔZ/Z = n · (ΔA/A)
Z = AⁿBᵐ/Cᵖ → ΔZ/Z = n(ΔA/A) + m(ΔB/B) + p(ΔC/C)
🧠 Dimension Shortcut — Powers of T Velocity → T⁻¹ · Acceleration → T⁻² · Force → T⁻² (with M·L)
Power → T⁻³ · Pressure → T⁻² (with M·L⁻¹)
Rule: Each time you divide by time, T-power decreases by 1!
